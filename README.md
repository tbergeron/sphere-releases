# Sphere

Signed, notarized builds of Sphere.

## Install

Needs macOS 26 or later. Paste this in Terminal:

```
curl -fsSL https://github.com/tbergeron/sphere-releases/releases/latest/download/install.sh | bash
```

It downloads the latest Sphere.app to `~/Applications`, starts it at login, and opens it. Updates arrive on their own (turn that off in Settings → About & Updates).

Every build is on the [Releases](https://github.com/tbergeron/sphere-releases/releases) page.
